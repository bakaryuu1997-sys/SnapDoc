## 2. Ghi Nhận Điểm Khác Biệt & Lý Do Kỹ Thuật

1. **Task T1 (`.snapdoc` file format):**
   - Định dạng container `.snapdoc` sử dụng chuẩn nén ZIP `CompressionMethod::Deflated`. Cả hai tệp `base_png` và `preview_png` đều được nén compact thông qua `encode_png_compact` trước khi đóng gói vào ZIP, giúp dung lượng tệp lưu trữ lịch sử giảm tối đa mà không thay đổi cấu trúc file hay làm chậm quá trình hiển thị.
2. **Task T4 (Windows Native Clipboard):**
   - Sử dụng trực tiếp Win32 API thông qua crate `windows-sys` (`CF_HDROP`, `CF_HTML`, `CF_DIB`), cấp phát bộ nhớ toàn cục với cờ `GHND` và xử lý chuỗi Unicode UTF-16 kết thúc bằng ký tự null kép (`\0\0`). Đảm bảo các đường dẫn chứa ký tự tiếng Việt có dấu (`dự án`) và tiếng Nhật (`マイドライブ`) được dán chính xác 100% vào Explorer và các ứng dụng chat.
   - Nhánh macOS trả về `Err("Chưa hỗ trợ trên macOS".into())` có cấu trúc rõ ràng, giữ trọn vẹn khả năng biên dịch đa nền tảng cho macOS mà không gây lỗi build.
3. **Task T7 (Thư viện QR Code):**
   - Tích hợp thư viện `jsqr` hoàn toàn offline (kèm type definition native), chạy trực tiếp trong client TypeScript với ImageData trích xuất từ Canvas. Thêm guard an toàn môi trường (`typeof Image !== "undefined"`) để tương thích tuyệt đối cả trong trình duyệt lẫn môi trường kiểm thử Vitest/Node.js.

## 5. Giới Hạn Đã Biết (Known Limitations)

1. **Dòng văn bản trộn lẫn CJK và tiếng Việt có dấu trong cùng một box đơn:**
   - Trường hợp một từ ngữ hoặc cụm ký tự xuất hiện cả chữ tượng hình Nhật/Trung và chữ cái tiếng Việt trong cùng một box (bounding box duy nhất), thuật toán phân loại phát hiện có CJK sẽ giữ kết quả của model CJK (PP-OCRv5) để tránh làm hỏng chữ tượng hình. Điều này có thể khiến một số dấu thanh tiếng Việt trong box đó không được bảo toàn trọn vẹn như khi dùng thuần `rec_vi.onnx`.
2. **Copy nhiều ảnh trên nền tảng macOS:**
   - Cơ chế clipboard hiện tại sử dụng `CF_HDROP` / Win32 API trên Windows. Khi chạy trên macOS, hàm `copy_images_multi` sẽ trả về lỗi `Chưa hỗ trợ trên macOS` an toàn mà không làm sập ứng dụng.
